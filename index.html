① 저장소 열쇠

내 비공개 저장소()에 글자를 쌓으려면 GitHub 전용 열쇠가 한 번 필요해요. 열쇠는 이 휴대폰 안에만 저장돼요.

열쇠 발급 방법 보기
    열쇠 발급 페이지 열기 ↗

    ② 로고 변경

    여기서 바꾸면 앱 안의 로고가 바로 바뀌어요. 홈 화면 아이콘은 아이폰이 “홈 화면에 추가”할 때 한 번 찍어두는 그림이라, 바꾸려면 홈 화면 아이콘을 지우고 Safari에서 원하는 로고를 고른 다음 다시 추가해야 해요. (그때는 열쇠도 다시 넣어야 해요)

    ③ 홈 화면에 앱으로 깔기

    1. 아이폰 Safari로 이 주소를 열어요. 홈 화면 아이콘을 고르고 싶으면 먼저 위 ② 로고 변경에서 골라요.
    2. 아래쪽 공유 버튼(네모에서 화살표가 위로 나가는 모양)을 눌러요.
    3. 홈 화면에 추가를 누르면 하트 아이콘이 생겨요.
    4. 열쇠는 홈 화면의 하트 앱을 연 뒤에 넣어주세요. (Safari와 앱은 저장 공간이 따로예요)

    ④ 대본 만들기 열쇠 (Claude)

    대본 뽑기는 Claude API로 돌아가요. Claude 구독과는 따로, 쓴 만큼 API 크레딧이 나가요. 대본 1편에 대략 200~500원(Fable 5.1), 주제 뽑기는 1원 안팎(Haiku). 열쇠는 이 휴대폰 안에만 저장되고 Claude 서버 말고는 어디로도 보내지 않아요.

    열쇠 발급 방법 보기
    1. 아래 버튼으로 Claude 콘솔을 열고 로그인해요. (Claude 앱과 같은 이메일로 가입해도 돼요)
    2. Settings → Billing에서 크레딧을 충전해요. 처음엔 5달러면 대본 수십 편이에요.
    3. API keys → Create key를 누르고 이름을 sowon-phone으로 적어요.
    4. 나온 sk-ant-… 글자를 복사해서 위 칸에 붙여넣어요. (그 화면을 벗어나면 다시 볼 수 없어요)
    5. 홈 화면의 하트 앱 안에서 넣어야 해요. Safari와 앱은 저장 공간이 따로예요.
